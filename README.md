# git-commit-guard
专门为大模型（Codex/GPT-4/Claude等）设计的 AI 技能配置（Skill/Prompt）。它强制 AI 在执行任何编码任务前，必须遵守一套极其严格的“Git 优先”工作流：  ✨ 核心亮点：  工作树保护机制：AI 动手前必须先检查 git status，如果有未提交的“脏代码”，必须先评估、测试并规范提交，绝不默默覆盖你的心血。  强制前置验证：拦截无效提交。AI 在 commit 前必须运行项目中合理的验证命令（Lint、类型检查、单元测试）。  结构化高质量中文 Commit：内置一套严谨的中文提交模板（包含背景、变更、验证、说明四大部分），让 AI 产出的每一次 commit 都像资深人类工程师一样清晰易读。
